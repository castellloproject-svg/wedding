## Guest Name

Gunakan format:

?to=Nama%20Tamu

Contoh:

?to=Anang%20Ma%27rup

## Install

npm install

## Development

npm run dev

## Production

npm run build

npm start

## Supabase

Buat project Supabase.

Buat tabel guestbook dengan SQL yang tersedia di dokumentasi project.

Tambahkan environment:

NEXT_PUBLIC_SUPABASE_URL

NEXT_PUBLIC_SUPABASE_ANON_KEY

## Assets

Masukkan foto ke:

public/images/

Masukkan dekorasi ke:

public/decorations/

Masukkan musik ke:

public/music/
